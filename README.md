# 魔法特許ゲーム

魔法を先に発明して特許を取り、他人が使うたびに使用料を稼ぐゲーム。
図形とテキストで表された「状況」を、「ベクトル」と単語でできた「魔法」で操作し、「指示」の達成をめざします。
5ラウンド遊んで、最後に所持金がいちばん多い人の勝ちです。

静的な HTML / CSS / JavaScript だけで動きます（ビルド不要・外部ライブラリなし）。GitHub Pages でそのまま公開できます。

## 遊び方

### モード

| モード | 内容 |
| --- | --- |
| 対戦 | 2〜4人。各席を人間かNPCに設定し、1台の端末を回して遊ぶ（ホットシート） |
| 一人遊び | あなた1人＋NPC |
| 観戦 | 全員NPC。バランス確認用 |
| ひとりで挑戦 | NPCなしの1人モード。行動段階の時間を計るタイム＋スコアアタック（下記） |

ゲームは自動でブラウザ（localStorage）に保存され、タイトル画面の「つづきから」で再開できます。

### 1ラウンドの流れ

1. **ヒント**：盤面と指示の一部だけが見えます。全体を予想して、魔法を2つまで無料で特許にできます（全体公開までは他の人に見えません）。
2. **全体公開**：盤面と指示の全体、全員の先行特許が公開されます。
3. **行動**：手番ごとに3回まで行動します。
   - 一時魔法で実行（1G）／特許魔法で実行（自分の特許は1G、他人の特許は1G＋使用料5G）
   - 特許申請（10G）／申請して実行（11G）／ゴミ箱の特許を拾う（無料）／特許を捨てる（0アクション）
4. **解答**：「解答する」を押すと、その時点の盤面で採点されます。達成率×300G と、解答の早さに応じた順位ボーナス（100 / 60 / 30 / 0G。達成率50%以上のときだけ）がもらえます。解答後は、そのラウンドの盤面は変えられず、特許の操作とクレームだけができます。
5. 全員が解答するか、全員の手番が6回に達したらラウンド終了。未解答の人は自動で解答したことになります（順位ボーナスなし）。

### 魔法

魔法は **単語（1〜4語）＋ベクトル（横・縦それぞれ −4〜+4）** でできています。

| 単語の種類 | 例 | 意味 |
| --- | --- | --- |
| 対象（形） | 四角, 円, 三角 | 対象を形で選ぶ |
| 対象（性質） | 赤い, 青い, 大きい, 小さい | 対象を中身の色や大きさで選ぶ（複数あれば両方を満たすもの） |
| 部位 | 枠, 中身 | 色をかける場所。省略すると両方 |
| 効果 | 赤に, 黄色に, 大きく, 小さく | 対象を変化させる |

例：「四角の枠だけ黄色に」＝［四角・枠・黄色に］(0, 0)

図形は盤面の外や、棚・床などの固定物には入れません（ぶつかる直前で止まります）。魔法を組み立てると、実行後の様子が盤面に点線でプレビューされます（無料）。

### クレーム

他人が **一時魔法** を実行した直後、その魔法が自分の特許に似ていればクレームできます（費用20G）。

- 類似度 ＝ 0.5 × ベクトルの類似度（向きと長さ）＋ 0.5 × 単語の重なり（Jaccard係数）
- 類似度10%以上なら成立し、相手から `100 × 類似度` G を受け取ります
- 不成立なら、相手に慰謝料5Gを払います
- 特許魔法として実行した魔法（「申請して実行」を含む）はクレームされません

### ひとりで挑戦（タイム＋スコアアタック）

NPCなしの1人モード。ルールを覚える練習や、自己ベストへの挑戦に。

- ヒント段階は時間を計らない。「ヒントを終える」を押すと、全体公開を挟まずに行動段階になり、計時が始まる
- 行動には**実行後の硬直**があり、その間は次の行動ができない（魔法の組み立てとプレビューはできる）。画面上部のバーで残りが分かる

  | 行動 | お金 | 硬直 |
  | --- | --- | --- |
  | 一時魔法で実行 | 3G | 3.0秒 |
  | 特許で実行 | 1G | 1.0秒 |
  | 特許申請 | 10G | 1.5秒 |
  | 申請して実行 | 11G | 2.0秒 |
  | 拾う／捨てる | 無料 | 1.0秒／0.5秒 |
  | 手番終了 | − | 1.0秒 |

- 特許は3枠まで。よく使う動作を特許にしておくと、お金も時間も節約できる
- 解答すると、達成率×300G と**タイムボーナス**（`100 × 達成率 × (1 − タイム/120秒)`、120秒で0）がもらえる。順位ボーナスはない
- スコア＝最終所持金。自己ベスト（スコアが高い方、同点ならタイムが短い方）はシードごとに保存される。最終結果の「同じシードで再挑戦」で同じ5問に挑める
- メニューを開いても時間は止まらない。「つづきから」で再開すると、中断した時点の経過時間から続く

## ローカルで動かす

ES Modules を使っているので、`file://` では動きません。簡易サーバーを立ててください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## テスト・シミュレーション（Node 20 以上）

```sh
npm test                                   # = node --test "tests/**/*.test.js"
node tools/simulate.js --games 100 --seed 1
node tools/simulate.js --games 100 --seed 1 --levels 3,2,1,1   # NPCの強さを席ごとに指定（1=よわい 2=ふつう 3=つよい）
node tools/simulate.js --games 100 --json                      # 結果をJSONで出力
```

シミュレーターは全員NPCで対戦し、所持金の分布、勝者の収入の内訳（達成報酬 / 使用料 / クレーム）、クレーム成功率などを出力します。

## 数値の調整

金額・人数・手番・盤面の大きさ・NPCのパラメータなど、数値はすべて [js/config.js](js/config.js) にまとまっています。ひとりで挑戦の値（特許枠・実行コスト・硬直・タイムボーナス）は `CONFIG.SOLO` です。
変更したら `node tools/simulate.js` でバランスを確認してください。

## パズルを追加する

[js/data/puzzles.js](js/data/puzzles.js) に1問ずつ定義します（盤面・指示文・達成条件・ヒント・使える単語・解の魔法列）。
`npm test` で、盤面の妥当性と「solution を適用すると達成率100%になること」が自動で検証されます。

## ファイル構成

```
index.html
css/style.css
js/
  main.js            起動・画面遷移（状態の更新は必ず engine の dispatch を通す）
  config.js          数値
  rng.js             シード付き乱数
  data/              単語辞書・パズル定義
  engine/            DOMに依存しない純粋ロジック（盤面・魔法・判定・類似度・特許・状態遷移・保存）
  ai/                NPC（候補の探索と意思決定）
  ui/                描画（盤面SVG・魔法作成パネル・特許一覧・ログ・各画面）
tests/               node --test 用
tools/simulate.js    全員NPCで大量対戦して統計を出す
DECISIONS.md         実装中に決めたこと
```

## GitHub Pages で公開する

1. このリポジトリを GitHub に push する
2. GitHub のリポジトリで **Settings → Pages** を開く
3. **Build and deployment** の Source を **Deploy from a branch** にし、Branch を `main`、フォルダを `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

パスはすべて相対パスなので、サブパス（`/<リポジトリ名>/`）でもそのまま動きます。
